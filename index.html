01 / ABOUT

I'm interested in what sits underneath the abstraction.

I grew up using computers without thinking much about what made them work. Computer science changed that. The more layers I peel back, the more interesting software gets: protocols, runtimes, databases, operating systems, distributed state, interfaces, and all the trade-offs engineers hide behind a simple button.

I'm still a student, so this portfolio is deliberately about work I can explain and defend, not a wall of inflated skill bars. Every project here is either something I'm actively building or something whose code is public enough to inspect.
